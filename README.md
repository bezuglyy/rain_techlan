# Techlan Полив (rain_techlan)

Home Assistant интеграция: **Rain Bird IQ4 (облако) + камера-детектор осадков с зонами**.

## Возможности
- **Полив (Rain Bird IQ4, мобильный app-канал):** спутники, зоны (`Зона N: полив`), время работы зон, задержка дождя (дни), питание контроллера,
  программы (статус/расписание), тревоги/предупреждения, датчики дождя и потока, связь; сервисы `start_zone`, `stop_zone`, `stop_all_zones`,
  `start_program`, `set_rain_delay`, `enable|disable_forecast_rain_delay`, `set_weather_adjust_*`, `scan`, `learn_dry`.
- **Осадки по камере (зрение без OpenCV — numpy+Pillow):** снимки с камер (HTTP, Basic-auth), зоны на кадре, признаки
  (глянец/рябь/резкость/затемнение/насыщенность), автоэталон «сухо» по световым режимам, оценка 0…1 и вердикт
  (`сухо/возможно/дождь`), сущности: оценка, вердикт, «дождь (камера)» и **кадры с разметкой зон** (`image`).
- **Запреты (interlocks):** правило «сенсор → условие → блокировать запуск зоны/программы» (режим block/warn).
- **Реакции:** обнаружение дождя → авто-стоп всего полива + уведомление; журнал событий.
- **Панель «Полив и осадки»** в боковом меню: рисование зон на кадре, пороги, «истина»-датчик, журнал, запреты, управление поливом, меню с выходом.

## Установка
1. Скопируйте `custom_components/rain_techlan` в `/config/custom_components/`.
2. Перезапустите Home Assistant и добавьте интеграцию: **Настройки → Устройства и службы → Добавить → Techlan Полив**.
3. Укажите почту/пароль Rain Bird IQ4. **Канал авторизации — `app`** (веб-канал на US free-tier не имеет прав управления).
4. В панели «Полив и осадки» добавьте камеры (URL снимка + логин/пароль) и нарисуйте зоны.

## Зависимости
`curl_cffi` (ставится автоматически при добавлении интеграции).
