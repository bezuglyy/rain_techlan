# Techlan Полив (rain_techlan)

Home Assistant интеграция: **Rain Bird IQ4 (облако) + камера-детектор осадков с зонами**.

## Возможности
- **Полив (Rain Bird IQ4, мобильный app-канал):** спутники, зоны (`Зона N: полив`), время работы зон, задержка дождя (дни), питание контроллера,
  программы (статус/расписание), тревоги/предупреждения, датчики дождя и потока, связь; сервисы `start_zone`, `stop_zone`, `stop_all_zones`,
  `start_program`, `set_rain_delay`, `enable|disable_forecast_rain_delay`, `set_weather_adjust_*`, `scan`, `learn_dry`.
- **Осадки по камере (зрение без OpenCV — numpy+Pillow):** снимки с камер (HTTP, Basic-auth), зоны на кадре, признаки
  (глянец/рябь/резкость/затемнение/насыщенность), автоэталон «сухо» по световым режимам, оценка 0…1 и вердикт
  (`сухо/возможно/дождь`), сущности: оценка, вердикт, «дождь (камера)» и **кадры с разметкой зон** (`image`).
- **Запреты (interlocks):** правило «сенсор → условие → блокировать запуск зоны/программы» (режим block/warn).
- **Реакции:** обнаружение дождя → авто-стоп всего полива + уведомление; журнал событий.
- **Панель «Полив и осадки»** в боковом меню: рисование зон на кадре, пороги, «истина»-датчик, журнал, запреты, управление поливом, меню с выходом.

## Установка
1. Скопируйте `custom_components/rain_techlan` в `/config/custom_components/`.
2. Перезапустите Home Assistant и добавьте интеграцию: **Настройки → Устройства и службы → Добавить → Techlan Полив**.
3. Укажите почту/пароль Rain Bird IQ4. **Канал авторизации — `app`** (веб-канал на US free-tier не имеет прав управления).
4. В панели «Полив и осадки» добавьте камеры (URL снимка + логин/пароль) и нарисуйте зоны.

## Зависимости
`curl_cffi` (ставится автоматически при добавлении интеграции).

## Что нового в 1.1.0
- **Раскладка камер 1 / 2 / 4** в панели; в раскладке «1 камера» — выбор, какую камеру показывать.
- **Полноценная правка зон:** перетаскивание, изменение размера за уголок, точные координаты (✎, `x,y,w,h` в %), удаление с подтверждением; режим правки включается кнопкой «✎ Редактировать зоны».
- **Ночная детекция по затемнению:** временное сравнение кадра с последними **сухими** замерами той же камеры/зоны (в ИК мокрое покрытие темнеет — подтверждено на реальном дожде: плитка −32 %, дорожка −63 %).
- **Гистерезис:** дождь подтверждается 2 проходами подряд, окончание — 3 сухими (защита от всплесков: фонарь, машина, смена режима).
- **Авто-пауза полива:** при подтверждённом дожде ставится **задержка на 1 день** (настраивается), при окончании дождя — снимается.
- **Реакция по «истине»:** авто-стоп работает и ночью по датчику дождя (met.no), даже если камера не видит воду.
- Кадр в панели — чистый (`raw_…`), сущностям `image` — размеченный (`last_…`), без дублирования рамок.
- Диагностика по зонам: базис «сухо» → текущий кадр → отклонение.

## Что нового в 1.2.0
- **Карточка «Сейчас»** (вердикт, источники «камера/датчик», полив, задержка, свежесть кадра) и **кнопки паузы 1/2/3/7 дней / снять**.
- **Логика «полив ≠ дождь»**: мокрое покрытие при работающем поливе и сухом прогнозе дождём не считается.
- **Пауза на дни — только при согласии источников** (камера + датчик, либо датчик при недоступной камере).
- **Fail-safe**: нет кадров и молчит датчик → состояние не меняется (в журнал «Камеры недоступны»).
- **Превентивный запрет старта** по прогнозу (`forecast_entities`: если «on» — полив не начинаем).
- **Сезонная адаптация порога** (`effective_threshold`).
- **Событие `rain_techlan_action`** (rain_start/rain_end/forecast_block) для автоматизаций; **сервис `simulate_rain`** — тест цепочки без дождя.
- **Интерфейс:** фильтры журнала + экспорт CSV/JSON, экспорт/импорт зон, **мобильная раскладка**, **мини-график 24 ч** (оценка + метки «истины»), отклонения по зонам.
